# Алгоритмы кэширования

## Сборка и тесты

Требуются CMake 3.16+, компилятор C++20 и Git. Если Catch2 3 не установлен,
CMake скачает Catch2 v3.16.0 с GitHub при первой конфигурации.

```sh
cmake -S . -B build
cmake --build build -j 4
ctest --test-dir build --output-on-failure
```
В тестах только работоспособность кэша, без тестов подсчета хитов.

Формат ввода в executable *_cli на stdin:
```
{размер кэша} {кол-во входных данных} {... входные данные}
```
Пока в cli только ввод типа int, хотя кэш шаблонный и может поддерживать любой тип.

Для сборки только программы без Catch2:

```sh
cmake -S . -B build -DBUILD_TESTING=OFF
cmake --build build
```
